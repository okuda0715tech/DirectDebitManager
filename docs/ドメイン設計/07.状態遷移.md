# 状態遷移

状態を持つエンティティについて整理する。

## 【例】TransferRelation

### 状態

【例】

* Created
* Active
* Stopped
* Deleted

### 状態遷移

【例】

```
Created → Active
Active → Stopped
Stopped → Active
Active → Deleted
```
