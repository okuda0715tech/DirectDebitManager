# ユースケース

ユーザーがシステムで行う操作を列挙する。

## ユースケース一覧

* 支払元を
  * 登録する
  * 表示する
  * 編集する
  * 削除する

* 支払先を
  * 登録する
  * 表示する
  * 編集する
  * 削除する

* 振替関係を
  * 登録する
  * 表示する
    * ツリー表示
    * フィルター表示
      * 支払元の分類
      * 支払元
      * 文字列検索
  * 編集する
  * 削除する

* 支払元の分類 (「クレカ」「銀行口座」「デビット」「その他」など)を
  * 登録する
  * 表示する
  * 編集する
