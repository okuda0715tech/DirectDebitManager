# ユースケース

ユーザーがシステムで行う操作を列挙する。

## ユースケース一覧

* 支払元を
  * 登録する
  * 表示する
  * 編集する
  * 削除する

* 支払先を登録する
* 支払先を表示する
* 支払先を編集する
* 支払先を削除する

* 振替関係を登録する
* 振替関係を表示する
  * ツリー表示
  * フィルター表示
    * 支払元の分類
    * 支払元
    * 文字列検索
* 振替関係を編集する
* 振替関係を削除する

* 支払元の分類を登録する (「クレカ」「銀行口座」「デビット」「その他」など)
* 支払元の分類を表示する
* 支払元の分類を編集する
