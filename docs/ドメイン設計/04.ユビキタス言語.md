# ユビキタス言語

ドメインで使う用語を定義する。

概念は何度か練り直すと、よい概念に落ち着きやすい。

---

## 概念１

発生した支払いに対して、お金が出ていくところ。

### 候補とその言葉のイメージ

* 支払元
  * 定期的な支払に限らず、全ての支払いを含むイメージがする。
* 振替元
  * 定期的な支払というイメージがする。
  * サービスに対する支払というより、銀行口座間のお金の移動や、銀行->クレカのお金の移動の感じがする。
* 引落口座
  * 口座というと銀行口座だけを対象としているイメージがする。
  * クレジットカードの支払元を示す画面には、この言葉が使われていることが多そう。

### 賛否の意見

* 支払元
* 振替元

### 言葉の決定とその採用理由

* 採用
  * 支払元
* 理由
  * 英語にすると Payer というしっくりくる単語があったため。

---

## 概念２

お金を支払う対象となるサービス。

### 候補とその言葉のイメージ

* 振替先
  * 口座からお金が引き落とされる対象
* 支払い先
  * ユーザーがお金を支払う相手
* 請求元
  * 請求を発行する会社
* 引き落とし先
  * 銀行口座から自動的にお金が引き落とされる相手
* 利用サービス
  * 利用料は、必ず「何かを利用したことによって発生している」という点では、相性が良さそう

### 賛否の意見

* 振替先
  * 銀行用語っぽい
  * 一般ユーザーが使う言葉ではない
* 支払い先
  * 手動支払いも含みそう
* 請求元
  * 請求書前提
* 引き落とし先
  * 意味は近いが長い

### 言葉の決定とその採用理由

* 採用
  * 支払い先
* 理由
  * 一般ユーザーが理解しやすい
  * サービスにも会社にも使える

---

## 概念３

支払先と支払元を紐づける。

### 候補とその言葉のイメージ

* 支払関係
  * 支払先と支払元を関係づける概念のように感じる
  * 「関係」という言葉が「紐づけ」というイメージに直結しずらい感じがする
* 支払情報
  * 支払元と支払先以外の情報も含んでいる感じがする
* 振替関係
  * 支払先と支払元を関係づける概念のように感じる
* 振替情報
  * 支払先と支払元が対等な関係である感じがする
  * 支払元と支払先以外の情報も含んでいる感じがする
* 振替
  * 一番シンプルで、余計な言葉が一切ない感じがする
* 引落情報
  * クレジットカードや電気料金などの UI などで使われるイメージ
  * 支払先が主語になっている感じがする

### 賛否の意見

* 支払関係
  * 否定
    * 支払という言葉は何度も出てくるので、ここでは使いたくない気がする。
* 振替
  * 否定
    * シンプルすぎて、「振替元と振替先の紐づけ」というニュアンスが薄れる感じがする
* 引落情報
  * 否定
    * 「振替元と振替先の紐づけ」というニュアンスが薄れる感じがする

### 言葉の決定とその採用理由

* 採用
  * 振替関係
* 理由
  * 支払先と支払元を関係づける概念のように感じる
  * 他のニュアンスが一番少なく、誤解を招きにくいと感じる

## 概念４

状況によって、支払先にもなるし、支払元にもなるもの

### 候補とその言葉のイメージ

* 支払
  * 支払元か支払先かをあいまいにしたイメージ
* 支払オブジェクト
  * 「支払」だと漠然としすぎている。
  * 「支払オブジェクト」だと、少し、支払元なのか支払先なのかをイメージしやすいようになった気がする
* 支払中継者
  * 「支払元」と「支払先」の間に入っている感じがする
* 支払コネクター
  * 支払中継者を英語っぽくした
* 中間支払者
  * 最終的な「支払元」と「支払先」の中継をしているだけの存在というイメージが湧いてくる。

### 賛否の意見

* 中間支払者
  * 実際には中間ではなく、末端になる場合もあると思うが大丈夫だろうか？
    * 中間支払者に末端が登録されるまでは、自分自身が末端になるとは思うが、それは一時的な状態にすぎず、実際の役割としては中間なので問題ないのでは？

### 言葉の決定とその採用理由

* 採用
  * 中間支払者
* 理由
  * 英単語では、 MidPayer という名前にすれば、短くて読みやすいと感じたため。
  * 意味的に誤解される可能性が少ないと感じたため。

## ユビキタス言語辞書

| 用語(日本語) | 用語(英語)       | 意味                                           |
| ------------ | ---------------- | ---------------------------------------------- |
| 支払元       | Payer            | 発生した支払いに対して、お金が出ていくところ   |
| 支払先       | Payee            | お金を支払う対象となるサービス                 |
| 中間支払者   | MidPayer         | 最終的な「支払元」と「支払先」の中継をするもの |
| 振替関係     | TransferRelation | 支払先と支払元の紐づけ                         |
